# data

Three layers, in the order data moves through them — standard `raw` →
`interim` → `processed` staging, so it's always obvious how far along the
pipeline a given file is and whether it's safe to regenerate.

## `raw/`

Untouched source files, exactly as collected — nothing in this repo ever
writes into `raw/`, only reads from it.

| File | What it is |
|---|---|
| `38000_review.csv` | The full review dataset: 31,938 rows across 5 brands (Audi, BMW, INFINITI, Lexus, Mercedes-Benz). |
| `3700_review.csv` | A separate 3,700-review reference sample that ships with pre-existing gold sentiment labels. Never used for training — only for validating the sentiment classifier in `sentiment_classification/`. |

## `interim/`

Working artifacts produced partway through the pipeline — inputs to a
later step, not final outputs anyone downstream should treat as stable.
Regeneratable by re-running the notebook that produced them.

| File | Produced by | Consumed by |
|---|---|---|
| `38000_processed.csv` | Manual reconciliation of `eda/EDA_NPL_38K.ipynb`'s flagged rows | `sentiment_classification/`, `topic_modelling/` (as `MAIN_PATH`) |
| `phase3_38k_flagged.csv` *(not checked in — ephemeral working file)* | `eda/EDA_NPL_38K.ipynb` | Manual review pass that produces `38000_processed.csv` |
| `phase4_model_comparison.csv` | `sentiment_classification/sentimentclassification.ipynb` | Human read-through when picking the winning model — not read by any code |
| `phase5_topic_info_1.csv` | An earlier run of `topic_modelling/topicmodelling.ipynb` | Superseded by `data/processed/phase5_topic_info.csv`; kept for reference |

## `processed/`

Final, stable tables — this is what `mcp_server/` actually reads (see the
[top-level README](../README.md#tool--data-file-map) for the tool → file
map). Nothing here should be hand-edited; each file is regenerated by its
producing notebook/script if it needs to change.

| File | Produced by |
|---|---|
| `brand_stats.csv` | `eda/EDA.ipynb` |
| `rating_trends.csv` | `eda/EDA.ipynb` |
| `cleaned_reviews.csv` | `eda/EDA_NPL_38K.ipynb` |
| `reference_validation.csv` | `eda/EDA_NLP_3700.ipynb` (validation-only, not read by the MCP server) |
| `aspect_sentiment_table.csv` | `topic_modelling/topicmodelling.ipynb` |
| `phase5_topic_info.csv` | `topic_modelling/build_topic_info.py` |
